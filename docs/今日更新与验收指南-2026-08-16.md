## 一、今日功能更新列表

### 🎭 新功能：模拟法庭（核心亮点）

| 编号 | 功能 | 说明 |
|------|------|------|
| 1 | **双阶段庭审** | 课前法庭（PRE，学完前）/ 课后法庭（POST，学完后）两场独立庭审 |
| 2 | **同一案件复用** | 课前/课后共用同一份 AI 生成的案件，便于对比认知变化 |
| 3 | **案例按知识点生成** | 以课堂关联的知识点（名称+内容）为素材，LLM 结构化生成贴合的案件 |
| 4 | **学生扮演法官** | 学生主持庭审、提问原被告、最终判决；AI 扮演原告/被告对抗 |
| 5 | **五环节庭审流程** | 陈述 → 答辩 → 举证质证 → 法庭辩论 → 判决（AI 自动推进，法官可随时干预） |
| 6 | **结构化判决** | 支持原告诉请 / 驳回诉讼请求 / 部分支持 + 判决理由 |
| 7 | **AI 成长分析报告** | 两份判决齐全后生成：认知变化轨迹 → 知识掌握评估 → 学习建议 |
| 8 | **法庭聊天室界面** | 角色气泡（书记员/原告/被告/法官）+ 快捷指令 + 案件信息卡 |
| 9 | **入口** | 智慧课堂列表每张课堂卡片的「模拟法庭」按钮（按学习进度自动进入 PRE/POST） |
