📚 我的课程

学生登录后的课程管理页面：

  • 查看已选课程 — 列表展示已加入的课程
  • 选课 — 点击右上角「选课」按钮，从可选课程列表中选择
  • 退课 — 操作列点击「退课」确认后移除
  • 开始学习 — 点击「开始学习」跳转到课程学习页面

侧边栏的「当前课程」下拉选择器会同步显示你选中的课程，所有学习模块都跟随该课程切换。

📖 课程学习

核心学习页面，访问 /student/learning/:courseCode。

页面结构

  • 左侧：知识点导航 — 所有知识点列表，带掌握度状态标签（未学习 待巩固 学习中 已掌握）
  • 右侧上方：学习内容 — 当前知识点的详细说明
  • 右侧下方：练习题 — 6 种题型：单选、多选、判断、填空、简答、论述

答题流程：选择答案 / 输入内容 → 点击「提交答案」→ 即时反馈正误 + 解析 → 正确后掌握度自动更新。

💡 提示：每个知识点至少 3 道练习题，题型由 AI 自动生成。

📊 学情总览

学生仪表盘，按课程展示学习数据：

  • 学习进度 — 已掌握/学习中/待巩固知识点数量
  • 雷达图 — 6 维度能力分析（知识掌握、理解应用、分析推理等）
  • 薄弱知识点 — 掌握度低于 50% 的知识点列表
  • 今日学习建议 — 基于学情数据生成的个性化建议
  • 答题热力图 — 学习活跃度日历

侧边栏切换课程后，学情数据自动跟随刷新。

🗺️ 学习路径

按先修关系规划的学习路线，三种策略：

策略说明适用场景
均衡推荐按先修+难度排序，跳过已掌握日常学习
最短路径跳过已掌握，动态缩短考前冲刺
拓展探索保留全部知识点，薄弱点优先查漏补缺

🤖 智能答疑

基于 RAG（检索增强生成）的 AI 辅导：

  • 向量检索 — 从课程知识点向量库中检索最相关内容
  • DeepSeek 回答 — 基于检索到的课程内容 + 自身知识生成回答
  • 课程关联 — 自动按当前选中的课程过滤知识库

提问示例：「Python中的列表支持哪些操作？」、「法的本质是什么？」

📝 错题复盘

错题管理和艾宾浩斯复习计划：

  • 错题列表 — 题目内容、我的答案（橙色）、正确答案（绿色）、错误类型、日期
  • 复盘反思 — 弹窗查看题目详情，填写反思笔记
  • 复习计划 — 1天/3天/7天/14天/30天后复习的艾宾浩斯节奏

👨‍🏫 教学智慧驾驶舱

教师端核心面板，按课程查看：

  • 班级概览 — 学生数、平均正确率、薄弱知识点
  • 知识点掌握度 — 全班各知识点正确率柱状图
  • 预警分布 — 需要重点关注的学生
  • 学生列表 — 姓名、班级、正确率、薄弱知识点、预警等级
  • 教学建议 — AI 生成的策略建议

📋 课程管理

教师课程列表 /teacher/courses：

  • 创建课程 — 填写编号、名称、描述、学科、年级
  • 发布/下架 — 切换课程发布状态
  • 进入课程管理 — 点击课程进入内容管理页面

📝 课程内容管理

在课程管理页面的「📝 课程内容」Tab 中，教师可以直接维护知识点和习题：

知识点管理

  • ✅ 查看知识点列表（名称/描述/内容/难度）
  • ✏️ 编辑知识点名称、描述、详细内容
  • ➕ 新增知识点
  • 🗑️ 删除知识点（关联习题一并删除）

习题管理

  • 📖 展开知识点查看其习题列表
  • ✏️ 编辑题目、类型、选项、答案、解析
  • ➕ 新增习题（支持 6 种题型）
  • 🗑️ 删除习题

📤 资料管理

在「📄 资料管理」Tab 中：

  • 上传资料 — 支持 .txt .md .html .json .csv .pdf .docx .xlsx .pptx
  • 批量上传 — 可选择多个文件或拖拽文件夹
  • 资料列表 — 上传后显示状态（待处理/AI提取中/已提取/已发布）

🤖 AI 提取

核心功能：将课程资料自动转换为知识点和习题：

1
上传资料 — 课程教材、教案、PPT 等
2
AI 提取 — 点击「AI 提取」按钮，DeepSeek 自动提取知识点+关系+习题
3
查看结果 — 点击「查看结果」预览提取内容
4
发布 — 点击「发布」写入课程知识库并自动向量化
🤖 智能识别：系统自动判断资料类型——教材/教案正常提取知识点+习题；试卷/考题则只提取习题并分配到对应知识点。

大文件处理

超过 5000 字的文件会自动按章节结构拆分（识别"第X章"、"## 标题"等），分批调用 AI 提取后合并结果，确保完整覆盖。

习题集处理

文件名包含试卷/考题/试题/考试等关键词时，LLM 自动识别为习题集，只提取习题并标注对应的知识点名称，不生成新知识点。

🔧 常见问题

登录报 403

原因：CORS 配置未正确设置。
解决：确保 CORS_ALLOWED_ORIGINS 环境变量包含前端域名。

AI 提取报 500

原因：max-tokens 太小或 timeout 太短。
解决：设置 --llm.max-tokens=16384 --llm.timeout=600。

习题发布后学生端看不到

原因：LLM 返回的习题 content 字段为空。
解决：新代码已自动兼容 stem 字段和 options 降级，重新上传提取即可。

向量化失败

原因：数据库 embedding 列为 vector 类型但 JPA 期望 text。
解决：ALTER TABLE kp_embeddings ALTER COLUMN embedding TYPE text;

Flyway 校验失败

原因：迁移文件 checksum 不匹配。
解决：启动时加 --spring.flyway.enabled=false，或 DELETE FROM flyway_schema_history WHERE version='N';

学习路径报错

原因：数据库缺少 adapt_strategy 列。
解决：ALTER TABLE learning_paths ADD COLUMN adapt_strategy VARCHAR(32);
