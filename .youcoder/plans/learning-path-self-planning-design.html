目标与用户价值

把学习路径从「系统自动规划的单一结果」升级为「学生拥有完整自主权的路径创作平台」：

  1. 快速起步：为「法学概论」预置 4 条推荐路径模板（课程考试 / 纠纷解决 / 兴趣拓展 / 师范生备课），学生一键生成自己的路径
  2. 个性共创：学生不被模板束缚，可通过与 AI 对话（"我想重点学行政法为考研做准备"），由 AI 结合课程知识库与 RAG 检索，生成属于学生自己的独特路径
  3. 自由调整：生成后的路径支持增删节点、调整顺序、切换策略，学生始终拥有最终控制权
产品理念：路径模板是"脚手架"而非"牢笼"。AI 是"规划助手"而非"规划者"。学生可以一键采纳推荐，也可以完全自定义——所有路径最终都是"我的路径"。

数据模型（V19 迁移）

① 新增：path_templates（路径模板定义）

CREATE TABLE path_templates (
    id             UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    course_id      UUID NOT NULL REFERENCES courses(id),
    code           VARCHAR(32) NOT NULL,   -- EXAM / LITIGATION / INTEREST / TEACHING
    name           VARCHAR(128) NOT NULL,  -- 课程考试 / 纠纷解决 / 兴趣拓展 / 师范生备课
    description    TEXT,
    icon           VARCHAR(32),
    total_minutes  INT,                    -- 总课时（分钟）；INTEREST 为 NULL=不设限
    node_count     INT DEFAULT 0,          -- 节点数（静态模板冗余统计）
    is_visible     BOOLEAN DEFAULT TRUE,   -- 是否展示在推荐卡片区
    template_type  VARCHAR(16) DEFAULT 'STATIC',  -- STATIC / RULE_BY_STAGE（师范生备课=动态规则）
    sort_order     INT DEFAULT 0,
    created_at     TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at     TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE (course_id, code)
);

② 新增：path_template_nodes（模板节点，静态模板用）

CREATE TABLE path_template_nodes (
    id                    UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    template_id           UUID NOT NULL REFERENCES path_templates(id) ON DELETE CASCADE,
    knowledge_point_id    UUID NOT NULL REFERENCES knowledge_points(id),
    knowledge_point_name  VARCHAR(255) NOT NULL,  -- 名称快照
    order_index           INT DEFAULT 0,
    estimated_minutes     INT DEFAULT 30,          -- 单节点预估时长
    UNIQUE (template_id, knowledge_point_id)
);

③ 修改：learning_paths（学生路径加来源标记）

ALTER TABLE learning_paths
    ADD COLUMN IF NOT EXISTS source VARCHAR(16) DEFAULT 'AUTO',  -- AUTO/TEMPLATE/AI/CUSTOM
    ADD COLUMN IF NOT EXISTS template_id UUID REFERENCES path_templates(id) ON DELETE SET NULL;
CREATE INDEX IF NOT EXISTS idx_lp_source ON learning_paths (source);
设计说明：模板节点是静态快照（存 knowledge_point_name），生成学生路径时复制到 learning_path_nodes，之后模板改动不影响已生成的路径——保证学生路径稳定。

「法学概论」4 个预设模板

模板代码定位课时节点生成规则展示
课程考试 EXAM 应试导向、课时最少 48 课时（2880 分钟） 首先展示高频考点：解析 course_materials 中法学概论试卷（A/B 卷）→ 题目文本匹配知识点 → 按试卷出现频次降序选取，直至 ≈48 课时（AI 生成 + 人工抽检后落库） ✅ 推荐卡片
纠纷解决 LITIGATION 司法程序与证据实务 64 课时（3840 分钟） 关键词规则 + AI 复核：诉讼/程序/证据/司法/审判/仲裁/调解/民事/刑事/行政 相关知识点（含 V17 主题 ORDER_SAFETY/CIVIL_LAW/GOVERNANCE 归类） ✅ 推荐卡片
兴趣拓展 INTEREST 完整课程知识库 不显示课时上限（total_minutes=NULL，卡片显示"完整知识库"） 该课程全部 LEAF 知识点，全量覆盖 ✅ 推荐卡片
师范生备课 TEACHING 为备课目标学段而学 一课 = 4 课时（240 分钟），一课由几个相关知识点组成 动态规则（template_type=RULE_BY_STAGE）：每次由学生选择目标学段（小学/初中/高中/大学）→ 按 stage + 主题过滤 LEAF 知识点 → 按主题聚类分课（几个相关知识点 = 一课 = 240 分钟，深度备课） ✅ 推荐卡片（点击后先选学段）
已确认（v1.1）：① 兴趣拓展 = 不显示课时上限，卡片显示"完整知识库"；② 课程考试 = 按试卷高频考点优先选取；③ 师范生备课 = 目标学段每次由学生选择，一课（4 课时/240 分钟）由几个相关知识点组成（非每知识点 4 课时）；④ AI 规划不限制课程（跨全部课程知识库检索，当前仅法学概论一门）；⑤ 手动勾选编辑器（CUSTOM）与本轮一并实现。

API 设计

新增端点（PathController 扩展）

方法路径说明
GET/api/paths/templates?courseId=课程可用模板列表（is_visible=true，含节点数/课时/类型）
GET/api/paths/templates/{id}/preview?stage=&themeIds=模板节点预览（TEACHING 按学段/主题动态计算并分课；静态模板直接返回）
POST/api/paths/from-template从模板生成学生路径 {studentId, courseId, templateId, stage?, themeIds?} → 复制节点到 learning_path_nodes，source=TEMPLATE
POST/api/paths/custom手动勾选创建路径 {studentId, courseId, name, nodeIds: [knowledgePointId...]} → source=CUSTOM（知识树勾选编辑器）
POST/api/paths/ai-plan/start开启 AI 规划会话 {studentId, courseId?, goal} → 返回首轮 LLM 追问/建议 + sessionId（存 chat_history；courseId 可选=跨全部课程知识库）
POST/api/paths/ai-plan/chat多轮对话 {sessionId, message} → RAG 检索（不限课程）+ LLM chat；用户确认规划时 LLM 输出结构化 JSON，落库 DRAFT 路径
POST/api/paths/{id}/nodes自定义：追加节点（知识点 + 顺序），source 置 CUSTOM
DELETE/api/paths/{id}/nodes/{nodeId}自定义：移除节点
PUT/api/paths/{id}/nodes/reorder自定义：调整节点顺序

AI 对话式规划流程

① 学生描述目标
"我想重点学行政法，为考研做准备"
→
② RAG 检索课程知识库
VectorRAGEngine.retrieveByCourse
→
③ LLM 多轮对话
LLMService.chat 追问/澄清
→
④ 结构化输出路径
askStructured → JSON
→
⑤ 落库 DRAFT
learning_paths + nodes
环节要点
① 目标理解首轮 ai-plan/start：解析目标关键词 → 检索相关知识点（不限课程，当前仅法学概论；未来多课程时跨全部课程知识库）→ 返回给 LLM 作为候选池；LLM 判断信息是否足够，不足则追问（目标/时间预算/偏好主题/考试日期）
③ 多轮对话会话存 chat_history（sessionId），支持"更侧重实务/去掉太难的点/每天1小时"等自然语言调整；courseId 仅作候选池筛选（可选），路径 course_id 允许为空（跨课程）
④ 结构化输出LLM 输出 {name, description, estimatedMinutes, nodes: [{knowledgePointId, orderIndex, estimatedMinutes, reason}]}；后端校验 knowledgePointId 存在；对无效 ID 回退提示 LLM 重新选择
⑤ 落库source=AI；节点按 LLM 顺序写入 learning_path_nodes（status=PENDING）；前端立即展示预览
调整学生可继续对话微调（重新生成部分节点）或手动编辑（增删/换序）
质量保障：① 候选池限制在课程知识点内（courseId 强约束，LLM 不能编造课程外内容）；② askStructured 低温度 0.3 + JSON Schema 校验；③ 节点 reason 字段记录 AI 选择理由，学生对每条理由可提出异议并继续对话。

关键交互

  • 一键生成：调 from-template → 生成 DRAFT → 弹出"路径已生成"预览（节点数/总课时/第一个节点）→ 确认后 activate
  • 师范生备课：点卡片 → 弹出学段选择（4 Tab）→ 调 preview 显示动态节点数/分课预览 → 确认生成
  • AI 对话面板：右侧 Drawer/独立组件，多轮对话 + "生成路径"按钮（LLM 确认后展示节点清单，可逐条勾选）
  • 手动勾选编辑器（CUSTOM）："新建路径" → 知识树勾选（复用课程知识点树，Checkbox 多选，可搜索/按主题筛选）→ 已选列表实时预览 → 命名保存
  • 路径详情：现有 Steps 步骤条 + 新增 source 来源 Tag（模板/AI/自定义/自动）+ 节点操作（跳过/删除/前移后移）
