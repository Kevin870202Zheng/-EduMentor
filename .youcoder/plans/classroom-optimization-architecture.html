1.2 当前状态管理

usePlayback.ts (278 行) 是一个单一的 React Hook，管理以下状态：

  • state: 'idle' | 'playing' | 'paused' | 'live'
  • currentSceneIndex / currentActionIndex: 位置指针
  • actionTimerRef: setTimeout 控制自动播放
  • progressTimerRef: setInterval 进度上报

问题： 单一 hook 承载所有状态和逻辑，随着 TTS 播放控制、动画状态、音频状态等新能力的加入，会迅速膨胀到不可维护。

3.2 TTS 语音系统

架构分层

┌────────────────────────────────────────────┐
│              useTTSPlayer hook              │  ← 状态管理层
│  - isPlaying / isPaused / currentActionId   │
│  - volume / rate / duration / progress      │
│  - play() / pause() / stop() / prefetch()   │
├────────────────────────────────────────────┤
│              ttsService.ts                   │  ← API 服务层
│  - synthesize(text): Promise<AudioUrl>       │
│  - prefetchForScene(sceneId)               │
├────────────────────────────────────────────┤
│          AudioContext / HTMLAudioElement     │  ← 浏览器引擎层
│  - 音频解码 + 播放 + 事件监听               │
└────────────────────────────────────────────┘

数据流

1. 用户进入场景 → usePlayback 检测到第一个 speech Action
2. → ttsService.synthesize(action.text) → 后端 TTS API → 返回 audio URL
3. → 音频加载 → HTMLAudioElement.play()
4. → SpeechRenderer 收到 isPlaying=true → 显示波形动画
5. → 音频播放结束 → onEnded → usePlayback.nextAction()
6. → 预取下一个 speech 的音频（prefetchForScene）

接口定义

// ttsService.ts
export interface TTSRequest {
  text: string;
  voiceId?: string;      // 将来扩展
  rate?: number;         // 1.0 = normal
  language?: string;     // 自动检测
}

export interface TTSResponse {
  audioUrl: string;      // 临时音频 URL
  durationMs: number;    // 音频时长
  format: 'mp3' | 'wav' | 'ogg';
}

export async function synthesize(request: TTSRequest): Promise<TTSResponse>;
export async function prefetchSceneAudios(sceneId: string): Promise<void>;

hook 设计

// useTTSPlayer.ts
export function useTTSPlayer() {
  const [state, setState] = useState<TTSPlayerState>('idle');
  const audioRef = useRef<HTMLAudioElement | null>(null);
  const cacheRef = useRef<Map<string, string>>(new Map());  // text→audioUrl

  const play = useCallback(async (text: string, actionId: string) => {
    // 1. 检查缓存
    let audioUrl = cacheRef.current.get(text);
    if (!audioUrl) {
      const res = await synthesize({ text });
      audioUrl = res.audioUrl;
      cacheRef.current.set(text, audioUrl);
    }
    // 2. 创建/复用 Audio 元素
    const audio = new Audio(audioUrl);
    audioRef.current = audio;
    // 3. 事件绑定
    audio.onended = () => setState('completed');
    audio.onerror = () => setState('error');
    // 4. 播放
    await audio.play();
    setState('playing');
  }, []);

  const pause = useCallback(() => {
    audioRef.current?.pause();
    setState('paused');
  }, []);

  const stop = useCallback(() => {
    audioRef.current?.pause();
    audioRef.current = null;
    setState('idle');
  }, []);

  return { state, play, pause, stop, prefetch: prefetchSceneAudios };
}

4. 状态管理重构

4.1 当前 vs 目标

当前（usePlayback.ts）目标（usePlayback.ts + useTTSPlayer）
单一 hook:
- state 枚举
- scene/action 指针
- setTimeout 自动播放
- setInterval 进度上报
- Quiz 提交
- API 加载
 
usePlayback（精简）:
- scene/action 指针
- 进度上报
- Quiz 提交
- API 加载
- 调用 useTTSPlayer

useTTSPlayer（新增）:
- 音频播放状态
- play/pause/stop
- 缓存管理
- 播放链回调
