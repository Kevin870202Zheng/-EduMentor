专家评审意见与采纳说明

NEW

评审结论摘要

专家对本 PRD（v3.0）进行了技术评审，核心结论：多学段功能此前处于「半成品」状态，应优先补齐数据与前端链路，落地入口放在学生端「课程学习」页，采用「学段 × 主题」双维度导航。

专家同时提出一个关键待确认问题——当前数据库只有「法学概论」一门课程、1,354 个知识点尚未标记学段（stage 字段为空），应如何落地学段切换？并给出三个候选方案：

方案做法优点缺点结论
方案A 直接实现前端切换 UI，先用「按深度推断学段」的临时规则展示（深度1-2→小学，2-3→初中，3-5→高中，4-5→大学），后续再正式标注数据 最快出效果，无数据成本 展示的是「推断数据」而非真实学段数据，存在误导风险；临时规则下沉到 UI 层，后期返工 ❌ 不采纳
方案B 先做数据迁移——按知识点深度自动标记学段字段，再实现前端切换 UI，保证展示真实学段数据 数据真实可靠，前端展示与数据一致，可长期演进 迁移工作需要一次性投入，依赖人工抽检保证质量 ✅ 采纳（用户已确认）
方案C 先实现前端 UI 框架（学段 Tab + 主题卡片 + 知识阶梯），数据留空展示空状态，等运营填充学段数据 前端先行，运营可并行填充 上线初期页面大面积空态，用户体验差，且无法验收核心价值 ❌ 不采纳

当前 EduMentor 平台已具备以下功能基础：

  • 知识点管理：知识点树形结构（parent_kp_id 自引用），难度 difficulty 1-5 级，共 1,354 个知识点

❌ 核心缺失（现状核查结论）

产品目标

Goals

核心目标

在 EduMentor 平台上构建一套 「学段 × 深度 × 主题」三位一体的法律课程体系，覆盖从小学到大学的完整学段，使得：

  1. 分层清晰：同一法律主题在小学、初中、高中、大学有明确区分的深度等级
  2. 衔接自然：低学段知识点到高学段知识点之间有显式的进阶关系
  3. 路径贯通：学生可以沿着学段阶梯持续学习，系统自动适配当前学段深度
  4. 管理高效：教师可以跨学段管理课程内容，清晰看到知识点的深度分布
  5. 标准对齐：课程内容严格参照教育部课程标准和统编教材
  6. 一体化完整：真正实现大中小学法治教育一体化，避免内容重复或断层
  7. 成长可溯：学生在学段进阶时可回顾上一学段学习情况、给未来自己提问，系统生成以法治素养为核心的成长记录

关键用户场景

场景 A：学生跨学段学习

小明在小学阶段学习了"法律的特征"（深度1：知道法律有强制性），进入初中后系统学习"法律的特征"（深度2：理解法律的三个基本特征），到了高中再深入学习"法律的特征"（深度4：分析法律与道德、习俗的关系）。系统自动记录小明各阶段的掌握度，并推荐适合当前学段的学习内容。

场景 D：智能路径规划

场景 E：大中小学一体化贯通

场景 F：成长时光机 — 跨学段自我对话与成长记录

学段深度模型

Core Model

学段定义 (Education Stage)

将教育阶段划分为四个学段，每个学段对应不同的认知深度和教学要求：

学段 代码 年级/学段范围 课程载体 法治教育目标
小学 PRIMARY 1-6 年级 道德与法治 启蒙认知 — 建立规则意识、法律初步感知
初中 JUNIOR 7-9 年级 道德与法治 系统理解 — 掌握法律基础知识、宪法核心内容
高中 SENIOR 10-12 年级 思想政治·法律与生活 深入应用 — 法律分析、综合思辨、案例应用
大学 UNIVERSITY 本专科通用 《思想道德与法治》（公共必修）
法学专业课（选修）		 理论升华 — 法治理论系统掌握、法治思维养成、法治实践能力（对应教材第六至第八章）

深度等级 (Depth Level)

基于 Bloom 认知分类学，定义 5 级深度学习等级。与现有 difficulty 字段（1-5）含义不同：depth 描述认知层次，difficulty 描述学习难度。两者正交，但在迁移阶段因无独立 depth 数据，以 difficulty 作为 depth 的近似值回填（见 §10.3，属于可配置假设）。

深度 认知层级 对应标签 典型描述 示例
深度 1 识记 (Remember) 知道 · 识别 "我知道法律是什么" 能说出法律名称、识别法律标识
深度 2 理解 (Understand) 理解 · 解释 "我理解法律为什么要这样规定" 能用自己的话解释法律条文含义
深度 3 应用 (Apply) 应用 · 判断 "我能用法律知识判断对错" 能将法律应用于简单案例判断
深度 4 分析 (Analyze) 分析 · 区分 "我能分析复杂案例中的法律关系" 能区分不同法律关系的适用场景
深度 5 评价 (Evaluate) 评价 · 思辨 "我能评价法律的合理性和局限性" 能对法律规范进行批判性思考

学段 × 深度 映射矩阵

每个学段覆盖 2-3 个深度等级，相邻学段之间 重叠 1 个深度，确保平滑过渡（此矩阵同时是 §10 迁移规则的基础）：

学段 覆盖深度 认知发展特征
小学 PRIMARY 深度 1 → 深度 2 以具体形象思维为主，通过生活实例感知法律
⬇️ 进阶（深度 2 重叠）

10.3 课程级学段标注（人工锚点）

原则：课程学段是「真实学段数据」的锚点，由管理员/教师人工指定，不依赖推断。因为一门课程面向的受众是明确的（例如「法学概论」是大学通识课），其学段归属不应由知识点深度反推。

步骤操作说明
1导出课程清单管理员后台生成待标注课程列表（含课程名、subject、grade_level、知识点数量）
2逐门标注 courses.stage当前仅「法学概论」一门课，按实际教学对象标注（预计 UNIVERSITY），人工确认后落库
3标注 stage_order 起点若课程内知识点需按学段内教学顺序排序，迁移工具按现有 order_index 顺序写入

📐 与专家方案A「按深度推断」的关系

专家方案A的「深度1-2→小学、2-3→初中、3-5→高中、4-5→大学」规则并未被丢弃，而是降级为辅助规则：仅当一门课程被标注为跨学段课程（同一课程包含多个学段内容，当前不存在）时，其知识点 stage 才用该规则按 depth 拆分。单学段课程的 1,354 个知识点统一继承课程学段，保证与课程定位一致，避免「大学课程标出小学生知识点」的失真。

10.5 主题（theme）初标流程

阶段方法产出质量目标
① 关键词初标 为 8 个主题各维护一组核心关键词（如 CONSTITUTION ← 宪法/根本法/国家机构/基本权利…），按知识点 name + description 命中率打分 每个知识点获得 0-1 个候选主题及置信度 覆盖 ≥ 60% 知识点

③ 人工复核 管理员对「低置信度」与「随机抽检 10%」的知识点进行人工确认；复核结果回写覆盖机器结果 最终 theme_id 标注 + 复核记录表 抽检合格率 ≥ 95%

兜底：未完成 theme 标注的知识点在 ThemeGrid 中归入「未分类」入口（或暂不展示），不影响 stage 维度的课程学习（§11.6 空状态）。

环节内容

Student Flow

学生端新增体验

  1. 学段选择/自动识别：学生首次使用时选择当前学段（小学/初中/高中/大学），系统自动适配该学段的课程和深度。学生 profile 中的 grade 字段可自动映射到学段（映射表可配置），学生可手动调整。

  4. 学段自适应学习路径：规划学习路径时，系统根据学生当前学段，自动包含对应深度的知识点，同时可复习低学段薄弱知识点。
  5. 进阶推荐：当学生完成一个学段的某个主题学习后，系统提示"是否进入下一阶段学习"，并展示进阶后的知识点变化。

学段自适应路径规划算法（修改 PathService）

// 伪代码 — 学段感知的路径规划
function planPath(studentId, courseId, studentStage):
  // 1. 获取课程下所有知识点（现有逻辑）
  kps = getKpsByCourse(courseId)

  // 2. 新增：按学段过滤
  stageKps = kps.filter(kp => kp.stage == studentStage)

  // 3. 新增：检查低学段掌握度
  lowerStageKps = kps.filter(kp => kp.stage < studentStage)
  weakPoints = findWeakInLowerStages(studentId, lowerStageKps)

  // 4. 将薄弱低学段知识点作为前置复习加入路径
  if weakPoints:
    reviewPath = createReviewNodes(weakPoints)
    stageKps = reviewPath + stageKps  // 复习在前，新知在后

  // 5. 原有拓扑排序 + 难度排序
  sortedKps = topoSort(stageKps, prerequisiteMap)

  // 6. 创建路径（原有逻辑）
  createPath(sortedKps)

成长时光机：跨学段学习衔接与成长记录

Growth

功能概述

「成长时光机」是服务于学生跨学段成长的三大能力集合，帮助学生在学段进阶时：

  • 回望：查看上一学段的学习情况，巩固薄弱知识点
  • 前瞻：给未来自己提问，实现跨时空的自我对话
  • 记录：生成以法治素养培育情况为核心的完整成长档案

🎯 设计理念

学生不是"固定学段的用户"，而是沿着学段阶梯持续成长的个体。系统不仅要提供当前学段的内容，更要帮助学生"回头看"不忘来路、"向前看"种下期待、"记录全过程"见证法治素养的成长轨迹。

能力①：上一学段学习报告

触发时机：学生首次进入新学段时自动弹出；之后可在个人中心随时查看。

数据来源：现有 student_courses、知识点掌握度记录。无需新增表。

  • 进入新学段时首次自动弹出，之后可在个人中心随时查看
  • 薄弱知识点自动标记，并提供"一键复习"入口
  • 复习时使用低学段原版内容（保持认知一致性），而非高学段的加深版
  • 报告数据支持PDF导出，供家长/教师查看

能力②：给未来的自己提问（时光胶囊）

  • 在学习某个知识点时，学生可以写一个问题留给下一学段的自己，让学习变成一场跨时空的自我对话
  • 系统自动检测 source_stage 的下一个学段，学生也可手动选择目标学段
  • 进入新学段学习关联知识点时，自动弹出"你有一封来自过去的信"
  • 问题/回答的内容质量可以纳入学习参与度指标
  • 支持学习路径节点展示作为学习动机

能力③：法治素养成长档案

以法治素养为核心维度，记录学生从小学到大学的完整成长轨迹。法治素养五维评估模型：

维度含义小学示例初中示例高中示例大学示例

宪法意识 对宪法精神的理解与认同 认识国徽国旗 理解宪法基本原则 分析宪法监督机制 评价宪法与国家治理
