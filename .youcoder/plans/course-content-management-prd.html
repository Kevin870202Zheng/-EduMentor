产品负责人: Roosevelt | 生成日期: 2026-06-24

1. 💡 产品愿景

一句话：让教师上传课程原始资料，AI自动提取知识点网络，教师审核后形成结构化课程知识库，向量化后供给大模型做精准答疑。

当前状态 vs 目标状态：

维度现在（硬编码）目标（教师自助）
课程数据来源 Java 代码里写死 DataSeeder.java 教师上传 PDF/文档，AI 自动提取
知识点维护 改代码 → 重新编译 → 重新部署 教师直接在 Web 界面增删改
先修关系 代码中手动写 20 条 AI 自动识别 + 教师拖拽调整
习题 6 道硬编码选择题 AI 自动生成 + 教师审核
RAG 知识库 Mock 实现，没有真实向量库 每次维护后自动向量化到 PGVector
前端数据来源 硬编码 fallback 数据 从教师维护的结构化数据直接调用
课程标识 仅 UUID（不可读不可记） UUID + course_code 双标识，如 MATH101

2. 🎬 用户流程

📄 教师上传原始资料 → 🤖 AI 自动提取 → ✏️ 教师审核修改 → 💾 入库 + 🧠 向量化

Step-by-step 流程

步骤操作参与者系统动作
1 创建课程（填写课程编号） 教师 填写课程名称 + 课程编号（如 MATH101），系统校验唯一性后创建
2 上传课程资料（PDF/Word/TXT/Markdown） 教师 文件存储到服务器，解析文本内容
3 点击"AI 智能提取" 教师 → 系统 LLM 分析资料，结构化输出：
知识点列表 + 先修关系 + 习题 + 答案
4 预览 AI 提取结果 教师 展示知识点树形图 + 关系图 + 习题预览
5 审核/修改 教师 编辑知识点名称/描述/难度，拖拽调整顺序，增删习题
6 确认发布 教师 数据写入 PostgreSQL（course/knowledge_point/knowledge_relation/question）
7 自动向量化 系统自动 知识点内容 + 习题 → 向量数据库（PGVector），供 RAG 检索
8 后续维护 教师随时修改 修改后自动触发增量向量化

3.3 课程编号设计 (course_code)

设计决策：每门课程同时拥有 UUID（系统主键，JPA 关联用）和 course_code（业务标识，人可读，URL 中用）。

course_code 的使用场景：

场景用 UUID用 course_code
数据库主键 / 外键关联✅ 必须（FK 性能最优）❌
前端 URL 路由❌ /courses/a3f8e1c2.../manage✅ /courses/MATH101/manage
教师创建/管理课程❌ 记不住✅ 输入 "MATH101"
API 查询过滤✅ 支持✅ 也支持 ?courseCode=MATH101
RAG 检索过滤✅ course_id = UUID✅ course_code = 'MATH101'
日志 / 调试❌ 一堆 UUID 无法识别✅ 一眼认出是哪个课程

编号规则：教师创建课程时自行填写，系统校验唯一性。

推荐格式: 学科缩写 + 数字层级
例如: MATH101, CS201, PHYS301, ENG101, CHN101

贯穿所有关联表：

course_code = MATH101
    ├── knowledge_points: 全部 course_id → (MATH101 的 UUID)
    ├── course_materials: course_code = 'MATH101'（冗余字段，便于快速过滤和调试）
    ├── kp_embeddings:    course_code = 'MATH101'（冗余字段，便于日志识别）
    └── questions:        全部 course_id → (MATH101 的 UUID)

4. 🧠 AI 提取核心设计

4.1 提取内容

当教师上传一份课程资料（如"高等数学"教材章节），AI 需要提取以下结构化信息：

提取项说明输出结构
📌 知识点列表 从资料中自动识别核心知识点 名称、描述、难度(1-5)、类别(concept/method/formula/application)、父知识点
🔗 先修关系 知识点之间的依赖关系 [前提知识点 → 目标知识点]
📖 笔记/讲解内容 每个知识点的详细讲解内容 知识点ID → 讲解文本（Markdown格式）
❓ 习题与答案 自动生成配套练习题 题目、选项(选择题)/答案、解析、所属知识点、难度

4.3 向量化设计

向量化哪些内容？

向量化对象嵌入来源用途
知识点名称 + 讲解内容Embedding API学生对知识点提问时检索
习题题目 + 答案 + 解析Embedding API学生问同类题时推荐
课程资料原文（分块）Embedding API全文检索补充
先修关系（文本描述）Embedding API路径规划推理

PGVector 表结构：

CREATE TABLE kp_embeddings (
    id UUID PRIMARY KEY,
    kp_id UUID REFERENCES knowledge_points(id),
    content_type VARCHAR(20),    -- 'kp_description' | 'question' | 'material_chunk'
    chunk_text TEXT,
    embedding vector(1536),      -- OpenAI text-embedding-3-small 维度
    course_id UUID REFERENCES courses(id),
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_kp_embeddings_course ON kp_embeddings(course_id);
CREATE INDEX idx_kp_embeddings_vector ON kp_embeddings 
    USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);

-- 0. 为 courses 表添加课程编号字段（唯一、人类可读）

UPDATE courses SET course_code = 'MATH101' WHERE name LIKE '%高等数学%';
UPDATE courses SET course_code = 'MATH201' WHERE name LIKE '%线性代数%';
UPDATE courses SET course_code = 'CS101' WHERE name LIKE '%Python%';

-- 设置 NOT NULL + UNIQUE
ALTER TABLE courses ALTER COLUMN course_code SET NOT NULL;
ALTER TABLE courses ADD CONSTRAINT uk_courses_course_code UNIQUE (course_code);
CREATE INDEX idx_courses_course_code ON courses (course_code);

-- 1. 课程原始资料表
CREATE TABLE course_materials (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    course_id UUID NOT NULL REFERENCES courses(id),
    course_code VARCHAR(32) NOT NULL,        -- 冗余字段，方便直接按编号查询
    title VARCHAR(255) NOT NULL,
    file_type VARCHAR(20),       -- pdf / docx / txt / md
    file_path VARCHAR(500),
    raw_text TEXT,               -- 解析后的纯文本内容
    status VARCHAR(20) DEFAULT 'pending',  -- pending / extracted / published
    created_by UUID NOT NULL REFERENCES users(id),
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 2. 知识点向量嵌入表
CREATE TABLE kp_embeddings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    kp_id UUID REFERENCES knowledge_points(id) ON DELETE CASCADE,
    material_id UUID REFERENCES course_materials(id) ON DELETE CASCADE,
    content_type VARCHAR(30) NOT NULL,  -- 'kp_content' / 'question' / 'material_chunk'
    chunk_text TEXT NOT NULL,
    embedding vector(1536),
    course_id UUID NOT NULL REFERENCES courses(id),
    course_code VARCHAR(32) NOT NULL,    -- 冗余字段，方便日志和调试时直接识别
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_kp_embeddings_course ON kp_embeddings(course_id);
CREATE INDEX idx_kp_embeddings_course_code ON kp_embeddings(course_code);
CREATE INDEX idx_kp_embeddings_vector ON kp_embeddings 
    USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);
