Product Requirements Document — 沉浸式课堂播放器 2.0

版本: v2.0-draft 状态: 规划中 优先级: P0-P2 对标: OpenMAIC v1.x

1. 背景与问题陈述

1.1 现状

EduMentor 的"沉浸课堂"播放器已具备基本功能骨架：场景切换、Action 分发、Quiz 交互、讨论提示。然而与对标产品 OpenMAIC 的课堂体验相比，在以下四个维度存在显著差距：

  1. 视觉体验 — 完全无动画，所有组件静态渲染，场景切换无过渡
  2. 交互深度 — 无语音讲解（TTS），无 AI 讲师形象，无生成过程预览
  3. 内容渲染 — 白板仅为纯文本展示，无画布式 Slide 渲染器
  4. 反馈机制 — 用户执行操作后无振动反馈、过度动画、流畅的状态转换

2. 目标与范围

2.1 优化目标

  1. 用户体验目标： 将课堂体验从"在阅读文档"提升到"在参加一堂真实的 AI 课程"
  2. 视觉目标： 每个交互操作都有流畅的过渡动画，消除"生硬"和"突兀"
  3. 听觉目标： AI 教师拥有语音，实现"视听同步"的授课体验
  4. 内容目标： 课件从纯文本升级为富视觉内容（公式、代码高亮、图表、图片）
  5. 反馈目标： 生成过程的每个步骤可视化，用户始终知道"进度"

3. 功能需求详述

3.1 动画框架基础

需求描述

引入 framer-motion（即 motion）库作为统一动画引擎。所有组件的入场、出场、状态变更都通过 motion 组件实现，建立可复用的动画配置常量。

验收标准

  • package.json 添加 motion 依赖
  • 创建 src/pages/classroom/animations.ts 统一动画配置（fadeIn, slideUp, scaleIn, springPresets 等）
  • 至少 3 个核心渲染器组件使用 <motion.div> 包装并应用入场动画
  • 动画性能无视觉卡顿（60fps），使用 will-change 和 transform 优先

技术要点

  • 使用 AnimatePresence 实现组件卸载时的退出动画
  • 统一 Spring 配置：{ type: 'spring', stiffness: 300, damping: 28 }
  • 对 Ant Design 组件外层包裹 <motion.div> 而非直接替换 AntD 组件

3.2 渲染器组件动画化

需求描述

对以下组件逐一添加动画效果：

组件当前状态动画目标
SpeechRenderer纯文本卡片文字逐行 fadeIn + 卡片 scaleIn + 高亮时的辉光脉冲
WhiteboardRenderer虚线框 Card内容从左到右"书写"动画 + 元素渐次出现
QuizRenderer静态 Radio 组选项逐个滑入 + 选择后高亮 spring 动画 + 反馈 Alert 弹出
DiscussionRenderer紫色卡片头像部分弹跳进入 + 文字渐显 + 思考提示脉冲
SceneTransitionRenderer居中文本图标旋转/缩放 + 文字类型打字机效果 + 背景渐变色过渡
PauseForThoughtRenderer加载图标 + 文本三点跳动加载 + 淡入淡出循环

验收标准

  • 每个渲染器组件在上一个 Action 结束时播放"进入"动画
  • 动画时长控制在 300-500ms 内，不阻碍学习节奏
  • Quiz 提交后有"正确/错误"的弹簧反馈动画
  • 场景过渡时播放完整的过渡动画（1-2 秒）

3.3 TTS 语音系统 P0

需求描述

为 SpeechRenderer 添加 TTS 能力：当 AI 教师"讲话"时，自动读出讲解文本，实现视听同步授课。

功能需求

  • 后端 API： TTS 合成接口（支持 Edge TTS / 其他 Provider），接收文本返回音频 URL
  • 前端音频管理模块： useTTSPlayer hook — 播放控制（play/pause/stop/seek）、音量控制、速率控制
  • 音频状态管理： 当前正在播放的 Action ID、播放进度、错误处理
  • UI 反馈： SpeechRenderer 中添加音频波形动画或音量条视觉反馈
  • 自动播放链： TTS 播放结束后自动进入下一个 Action（取代原有的 setTimeout 自动播放）
  • 预缓存： 进入场景后预先合成当前场景所有 speech 音频

验收标准

  • 播放 speech 时自动同步播放语音，口型/波形有视觉反馈
  • 语音结束后自动跳转下一 Action
  • 暂停课堂时语音暂停，恢复时继续播放
  • 音频加载失败时有优雅降级（静默跳过 + Toast 提示）

非范围

  • 多种 TTS Provider 切换（v1 只支持浏览器 Native TTS + 一个后端 Provider）
  • 音色定制 / Voice 选择（未来版本考虑）
  • 多语言发音优化

3.4 AI 讲师形象 P1

需求描述

在课堂播放器右上角或侧边展示 AI 讲师形象，增强"被授课"的临场感。

功能需求

  • Avatar 组件： 3-5 种预设 AI 讲师头像（教师/助教风格），支持 SVG/PNG 格式
  • 入场动画： 场景开始时讲师头像从右侧滑入 + 弹跳效果
  • 讲话状态： 头像在 speech 播放时显示"说话"动画（呼吸/微动/边框辉光）
  • 角色切换： 不同场景可切换不同讲师（如主讲教师 → 讨论引导员）
  • 角色卡提示： 首次出现时展示简短的角色介绍卡片（翻牌动画）

验收标准

  • 播放器右上角固定显示讲师头像，不随场景内容滚动
  • 讲话时头像有脉冲/呼吸动画，停留时静态
  • 不同场景可配置不同讲师角色

3.5 场景侧边栏 2.0 P1

需求描述

将当前的水平文字 Button 导航改造为左侧垂直侧边栏，支持场景类型图标、缩略图预览（简易版）、拖拽调整宽度。

功能需求

  • 侧边栏容器： 左侧固定区域，默认宽度 220px，可折叠/展开
  • 场景列表： 每个场景显示序号 + 标题 + 类型图标（讲解/练习/讨论等）
  • 缩略图预览： 当前激活的场景显示简化的内容预览（文字摘要或图表骨架）
  • 拖拽调整： 侧边栏右边缘可拖拽调整宽度（170px - 400px）
  • 折叠按钮： 左上角汉堡按钮折叠侧边栏，为主内容区腾出空间
  • 生成中骨架： 正在生成的场景显示骨架屏动画

验收标准

  • 侧边栏在 1280px 宽度以上的屏幕默认展开
  • 拖拽调整宽度流畅无卡顿
  • 折叠后只有图标按钮，展开有平滑动画
  • 当前场景高亮显示，已完成场景有勾选标记

3.6 场景切换动画 P1

需求描述

当用户从一个场景导航到下一个场景时，使用流畅的页面级过渡动画代替生硬的"闪现"。

功能需求

  • 过渡方向： 前进时内容向左滑出/新内容从右侧滑入；后退时反之
  • SceneTransitionRenderer 增强： 显示场景标题的大号渐变文字、知识点标签、进度指示
  • 过渡时长： 主过渡动画 400ms，过渡卡片展示 1.5s - 2s 后自动进入首 Action
  • 跳过： 用户可点击跳过过渡动画直接进入内容

验收标准

  • 场景切换时有方向性滑动过渡
  • 过渡期间显示场景标题和知识点标签
  • 用户可点击跳过过渡

3.7 课件富化 (Whiteboard 升级) P2

需求描述

将当前的纯文本白板渲染器升级为富视觉内容渲染器，支持公式、代码高亮、Markdown 渲染。

功能需求

  • Markdown 渲染： 使用 react-markdown 或 marked（已有依赖）渲染白板内容
  • 代码高亮： 添加 react-syntax-highlighter 或 shiki 支持代码块
  • LaTeX 公式： 使用 katex 渲染数学公式
  • 图片支持： 白板内容中引用的图片 URL 可正常加载显示
  • 自适应布局： 内容在卡片中自适应居中/居左，长内容可滚动

验收标准

  • 包含 ```python print("hello")``` 的内容能正常高亮
  • 包含 $$E=mc^2$$ 的内容能正常渲染为公式
  • 图片能正常加载，有 loading 状态

4. 用户体验流程

4.1 理想用户体验旅程

  1. 进入课堂： 播放器整体淡入，左侧侧边栏展开显示场景列表，AI 讲师从右侧滑入
  2. 场景过渡： 场景切换时，过渡卡片从中心放大出现（1.5s），显示"场景 2/5：什么是变量"
  3. AI 讲解： SpeechRenderer 从底部滑入，文字逐行显示，AI 讲师头像开始"说话"动画，同步播放 TTS 语音
  4. 白板展示： WhiteboardRenderer 从左到右"书写"内容，代码行逐个高亮
  5. 随堂练习： Quiz 选项逐个从下方弹入，选择后正确选项 spring 放大，错误选项抖动反馈
  6. 讨论提示： 思考气泡脉冲放大，展示思考问题
  7. 课堂完成： 庆祝动画（🎉 彩花效果），显示完成统计

5. 非功能需求

维度要求
性能动画帧率 ≥ 55fps（使用 transform 和 opacity 优先，避免 Layout 触发重排）
可访问性用户可通过设置关闭动画（prefers-reduced-motion）；文字内容始终可读
兼容性支持 Chrome 90+ / Edge 90+ / Safari 15+
包体积motion 库按需引入，Tree-shaking 后增量 ≤ 15KB gzipped
可维护性动画配置集中管理（animations.ts），不散落在组件中
