# 幻灯片布局规则手册 v2（slide / review 场景通用）

当场景类型为 slide 或 review（总结页思维导图）时，除生成 teacherScript 外，必须生成 `content.slides[]`（元素级幻灯片布局），并通过 `show_slide` 动作逐页展示。

**页数要求（视觉常驻范式）**：slide 场景生成 **2~4 页** slides（开场页 + 图表/要点页 + 归纳页），每页支撑 1~2 段讲解；禁止只生成 1 页。幻灯片一经展示即常驻屏幕，讲解期间不消失。

---

## 一、画布规范（硬约束）

- 画布尺寸：**960 × 540**（16:9），元素坐标 `(x, y, w, h)` 均为画布内绝对坐标（左上角原点）
- 边距：四周距画布边缘 ≥ 60px；元素间水平间距 ≥ 20px，垂直间距 ≥ 30px
- 安全区校验：`x ≥ 0 && x + w ≤ 960 && y ≥ 0 && y + h ≤ 540`（违反即 P0）
- 元素坐标对齐 20px 栅格（x/y/w/h 尽量为 20 的倍数或偶数）

---

## 二、元素类型（kind）与卡片变体（variant）

| kind | 说明 | 关键字段 |
|------|------|----------|
| `text` | 文本块（短句/词组） | content, fontSize, color, align(left/center/right), bold |
| `shape` | 色块/圆角卡片/圆形 | shape(rect/circle/round), fill(hex), radius, label(可选文字) |
| `line` | 连线/箭头 | from[x,y], to[x,y], arrow(bool), dashed(bool), color |
| `chart` | 图表 | chartType(bar/line/pie/radar), data{labels[], series[][], legends[]}, themeColors[] |
| `latex` | 公式（KaTeX 渲染） | latex, color, align |

**卡片变体 variant（可选，提升精致度）**：

| variant | 渲染效果 | 适用 |
|---------|----------|------|
| `card` | 浅色圆角卡片（12px 圆角 + 柔和阴影） | 要点分组、关键词卡 |
| `conclusion` | 左侧主色竖条 + 渐变底 + "⚡ 结论" 徽标 | 数据结论、页尾金句 |
| `highlight` | 高亮强调卡片 | 核心概念、重点法条 |

**image 元素 v1.1 支持，当前版本不要生成。**

---

## 三、文本尺寸查表（文字溢出 = P0，必须查表）

文字高度 ≈ 行数 × 字号 × 1.4（行高），向上取整到 2px 栅格。**元素 `h` 不得小于查表值**：

| 字号 | 1 行 | 2 行 | 3 行 | 4 行 | 5 行 |
|------|------|------|------|------|------|
| 36px（大标题） | 54 | 100 | 146 | 192 | 238 |
| 32px（页标题） | 48 | 88 | 128 | 168 | 208 |
| 28px（小节标题） | 42 | 78 | 114 | 150 | 186 |
| 24px（要点） | 38 | 70 | 102 | 134 | 166 |
| 20px（正文） | 32 | 60 | 88 | 116 | 144 |
| 16px（注释） | 26 | 50 | 74 | 98 | 122 |
| 14px（脚注） | 24 | 46 | 68 | 90 | 112 |

**文本宽度估算**：`w ≈ 字数 × 字号 × 1.0 + 内边距 × 2`（中文）；元素 `w` 不足时文字换行，行数按换行后重新查表。**字号层级**：标题 28~36 / 要点 20~24 / 正文 16~18 / 注释 14。

**单行字数上限**（按元素宽度）：
- 字号 24+：单行 ≤ 12 字（卡片内）/ ≤ 22 字（全宽横条）
- 字号 20：单行 ≤ 20 字（卡片内）/ ≤ 32 字（全宽横条）
- 字号 16：单行 ≤ 28 字（卡片内）/ ≤ 44 字（全宽横条）

---

## 四、对齐与对称规则

1. **同组元素对齐**：同列元素左边缘 x 值相同；同行元素顶部 y 值相同；偏差 ≤ 2px（人眼可察觉 5px 差异）
2. **水平居中**：`x = (960 - w) / 2`；垂直居中：`y = (540 - h) / 2`
3. **对称布局**（左右两栏/上下镜像）：两侧元素必须使用完全相同的 w/h 与对称 x（如左栏 x=60、右栏 x=500 且 w 相同），禁止"大致对称"
4. **卡片文字居中**：卡片内文字按 `textAlign` 对齐，padding 四周一致（≥ 12px），文字不得贴边

---

## 五、间距标准（分场景）

| 场景 | 间距 |
|------|------|
| 元素间垂直间距 | 20~50px |
| 多列之间（并排卡片/图表+说明） | 40~60px |
| 图表与其下方结论条 | 20~30px |
| 图（chart）与相关文字（标题/说明） | 25~35px |
| 标题与下方内容 | 24~40px |

## 六、反例对照（输出前对照自查）

**反例 1：文字溢出**
- ❌ Wrong：标题元素 `{x:60, y:40, w:840, h:60}`，fontSize 32，内容 3 行 → 文字被裁剪（查表 3 行应 h ≥ 128）
- ✅ Correct：`{x:60, y:36, w:840, h:128}`，fontSize 32，内容 ≤ 2 行（查表 2 行 h=88，留余量）

**反例 2：对齐错位**
- ❌ Wrong：左右对比卡 x 分别为 70 与 500（视觉错位），卡内文字左右 padding 不一致
- ✅ Correct：两卡 x=60 与 500（同宽 400、间距 40），卡内 padding 统一 16px

**反例 3：图表滥用/数据空洞**
- ❌ Wrong：chart 塞 6 项数据 label 超长被截断、无结论条、数字无出处
- ✅ Correct：chart 只放 3~5 项关键数据 + 下侧 conclusion 结论条点出要点，数据来自知识点

**反例 4：讲稿上屏**
- ❌ Wrong：text 元素 content 是完整长句（>25 字）口语化讲解词
- ✅ Correct：content 是 6~12 字关键词/短句（如 "罪刑法定"、"禁止类推解释"），完整讲解在 speech 动作里

## 七、配色主题系统（整套页面一致，每页主题色 ≤ 3 种）

从以下 5 套主题中**选 1 套**用于整场场景（theme 字段），元素 color/bg 可微调但不得偏离主题色系：

| theme | primary | secondary | light 浅底 | bg 渐变 | 适用 |
|-------|---------|-----------|-----------|---------|------|
| `academic` 学术蓝 | #1677ff | #69b1ff | #e6f4ff | #f5faff→#e6f4ff | 法律/社科等严谨学科 |
| `morandi` 莫兰迪绿 | #52c41a | #95de64 | #f6ffed | #fbfef6→#f6ffed | 生物/环保/农学 |
| `minimal` 极简黑白金 | #1a1a2e | #8c8c8c | #f5f5f5 | #ffffff→#f2f2f2 | 理工/数学/抽象概念 |
| `warm` 暖橙学术 | #fa8c16 | #ffc069 | #fff7e6 | #fffbf3→#fff7e6 | 历史/语文/人文 |
| `ocean` 深海蓝青 | #13c2c2 | #5cdbd3 | #e6fffb | #f2fdfd→#e6fffb | 地理/经济/数据类 |

文字默认 `#1a1a2e`；浅色卡片（light 底）内文字用深色；深色文字禁止用在高饱和背景上。

## 八、布局硬性规则（违反即不合格）

1. **每页 3~8 个元素**（卡片/图表/文本合计），禁止整段口语化文字上屏
2. **一句话 ≤ 25 字**：用关键词、短句、词组表达要点
3. **图表数据必须来源于知识点上下文**，禁止编造无依据数据；无真实数据时用 concept/flow 版式而非 chart
4. **公式必须用 latex 元素**，禁止把 `\frac`、`x^2` 等公式语法塞进 text 元素（会显示为原始文本）
5. **元素不得互相遮挡**（按查表规则估算尺寸；卡片内层叠除外）
6. **每页必须有明确视觉焦点**（最大字号标题 / 高亮色块卡片 / 图表主体），其余元素围绕焦点布置
7. **表达形式选择**：
   - 数据类（占比、趋势、对比、分布）→ 优先 `chart` + 下方 `conclusion` 结论条
   - 过程类（流程、步骤、时间线）→ `shape` 卡片 + `line` 连线（箭头）
   - 概念关系类（分类、层级、对比）→ `shape` 圆角卡片 + `line` 连线
   - 公式/定理 → `latex` + 标题
   - 核心概念/重点 → `shape` 卡片带 `variant: highlight` 或 `conclusion`

## 十、输出前自检清单

**🔴 P0（违反即失败，必须全部通过）**
- [ ] 所有元素在 960×540 画布内（x ≥ 0 && x+w ≤ 960 && y ≥ 0 && y+h ≤ 540）
- [ ] 每个 text 元素 h ≥ 文本高度查表值（无裁剪/溢出）
- [ ] 一句话 ≤ 25 字，无整段讲解词上屏
- [ ] 每页 3~8 个元素，有明确视觉焦点
- [ ] 元素两两不重叠（卡片内层叠除外）
- [ ] 图表数据来自知识点上下文（禁止编造数字）
- [ ] 公式用 latex 元素，text 元素内无 LaTeX 语法
- [ ] 元素 content 能在对应讲稿句的 keywords 中找到出处

**🟡 P1（强烈建议，违反需在说明中解释）**
- [ ] 同组元素对齐偏差 ≤ 2px；对称布局使用相同数值
- [ ] 间距符合分场景标准（垂直 20~50 / 多列 40~60 / 图文 25~35）
- [ ] 卡片圆角 12px、阴影柔和、整套页面主题一致（theme 字段）
- [ ] 页边距 ≥ 60px；坐标对齐 20px 栅格
- [ ] 每页至少 1 个非 text 元素（shape/line/chart）支撑版式
- [ ] 有数据结论时使用 conclusion 变体点出要点
