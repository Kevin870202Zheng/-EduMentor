# 幻灯片布局规则（slide 场景专用）

当场景类型为 slide 或 review（总结页思维导图）时，除生成 teacherScript 外，必须生成 `content.slides[]`（元素级幻灯片布局），并通过 `show_slide` 动作逐页展示。

**页数要求（视觉常驻范式）**：slide 场景生成 **2~4 页** slides（开场页 + 图表/要点页 + 归纳页），每页支撑 1~2 段讲解；禁止只生成 1 页。幻灯片一经展示即常驻屏幕，讲解期间不消失。

---

## 画布规范

- 画布尺寸：**960 × 540**（16:9）
- 元素坐标 `(x, y, w, h)` 均为画布内绝对坐标（左上角为原点）
- 边距：四周距画布边缘 ≥ 50px；元素间水平间距 ≥ 20px，垂直间距 ≥ 30px

---

## 元素类型（kind）

| kind | 说明 | 关键字段 | 示例 |
|------|------|----------|------|
| `text` | 文本块（短句/词组） | content, fontSize, color, align(left/center/right), bold | 标题、要点 |
| `shape` | 色块/圆角卡片/圆形 | shape(rect/circle/round), fill(hex), radius, label(可选文字) | 关键词卡片、高亮块 |
| `line` | 连线/箭头 | from[x,y], to[x,y], arrow(bool), dashed(bool), color | 流程箭头、思维导图连线 |
| `chart` | 图表 | chartType(bar/line/pie/radar), data{labels[], series[][], legends[]}, themeColors[] | 占比、趋势、对比 |
| `latex` | 公式（KaTeX 渲染） | latex, color, align | 数学公式、法律条文序号 |

**image 元素 v1.1 支持，当前版本不要生成。**

---

## 布局硬性规则（违反即不合格）

1. **每页 3~8 个元素**，禁止整段口语化文字上屏。
2. **一句话 ≤ 25 字**：用关键词、短句、词组表达要点，禁止把讲解词复制上屏。
3. **字号层级**：标题 28~32 / 要点 20~24 / 正文 16~18 / 注释 14。
4. **图表数据必须来源于知识点上下文**，禁止编造无依据数据。
5. **公式必须用 latex 元素**，禁止把 `\frac`、`x^2` 等公式语法塞进 text 元素（会显示为原始文本）。
6. **元素不得互相遮挡**：文字宽度 ≈ 字数 × 字号 × 1.0 + 内边距×2；文字高度 ≈ 行数 × 字号 × 1.5。
7. **每页必须有明确视觉焦点**（最大字号标题 或 高亮色块卡片）。
8. **表达形式选择**：
   - 数据类知识（占比、趋势、对比、分布）→ 优先 `chart`
   - 过程类知识（流程、步骤、时间线）→ `shape` 卡片 + `line` 连线
   - 概念关系类知识（分类、层级、对比）→ `shape` 圆角卡片 + `line` 连线
   - 公式/定理 → `latex` + 标题
9. **配色**：每页主题色不超过 3 种，建议使用 `#1677ff`(蓝) `#52c41a`(绿) `#faad14`(橙) `#ff4d4d`(红) `#722ed1`(紫) 及同色系浅底 `#f0f5ff` `#f6ffed` 等；文字默认 `#1a1a2e`，浅色卡片内文字用深色。

## 元素 JSON 示例

```json
{
  "layoutId": "s1",
  "title": "生活中的概率",
  "elements": [
    { "id": "t1", "kind": "text", "x": 60, "y": 80, "w": 840, "h": 76,
      "content": "抛硬币 100 次，正面朝上约 50 次", "fontSize": 28,
      "color": "#1a1a2e", "align": "center", "bold": true },
    { "id": "c1", "kind": "chart", "x": 140, "y": 200, "w": 480, "h": 280,
      "chartType": "bar",
      "data": { "labels": ["正", "反"], "series": [[51, 49]], "legends": ["次数"] },
      "themeColors": ["#1677ff", "#52c41a"] },
    { "id": "b1", "kind": "shape", "x": 680, "y": 230, "w": 220, "h": 120,
      "shape": "round", "fill": "#f0f5ff", "label": "P(正面) ≈ 1/2" },
    { "id": "l1", "kind": "line", "x": 640, "y": 290, "w": 40, "h": 1,
      "from": [0, 0], "to": [40, 0], "arrow": true, "color": "#1677ff" }
  ]
}
```

## P0 质量检查清单（输出前逐项核对）

- [ ] 所有坐标在 960×540 画布内，四周边距 ≥ 50px
- [ ] 元素间无遮挡（文字宽度/高度按规则计算）
- [ ] 每页 3~8 个元素，无整段讲解词上屏
- [ ] 一句话 ≤ 25 字，字号符合层级规范
- [ ] 图表数据来自知识点上下文
- [ ] 公式用 latex 元素，text 元素内无 LaTeX 语法
- [ ] 每页有明确视觉焦点
- [ ] 同层元素对齐（顶部对齐/水平居中），间距一致
